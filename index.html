Die App muss über einen Webserver laufen

Sie wurde gerade direkt aus dem Dateisystem geöffnet (file://). Chrome blockiert dort das Nachladen der Programmteile und verbietet den Datenspeicher – deshalb bleibt das Fenster leer. Das lässt sich nicht in der App beheben, es ist eine Sicherheitsregel des Browsers.

Zum Ausprobieren auf diesem Rechner: im Ordner der App eine PowerShell öffnen und starten:

powershell -ExecutionPolicy Bypass -File serve.ps1

Danach http://localhost:8080/ aufrufen. Fürs Handy zeigt das Skript zusätzlich eine Adresse im WLAN an.

Zum dauerhaften Installieren brauchst du HTTPS – der Weg über GitHub Pages steht in der README.md.
